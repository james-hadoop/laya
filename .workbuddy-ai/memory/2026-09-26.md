**环境**：`D:/_AllDocMap/06_Software/anaconda/python.exe`（Python 3.12.7），laya 0.3.20（源码加载，非 pip 安装），torch 2.14.0+cpu，transformers 5.17.0，huggingface_hub 1.33.0。

**产出**（`_james_work/` 下 3 个脚本，均已跑通）：

**关键坑（国内 Windows + WorkBuddy 沙箱环境）**：
1. **laya 未 pip 安装到 anaconda**：`import laya` 依赖工作目录恰为项目根。从 `_james_work` 运行必须 `PYTHONPATH=D:/_AllDocMap/02_Project/github/laya`。

3. **hf-xet 传输 CAS 服务 401**：多语言大模型下载报 `cas-server.xethub.hf.co 401 Unauthorized`。绕过：`HF_HUB_DISABLE_XET=1` 改走常规 HTTPS。
4. **Hugging Face 直连不通**（curl 000）：模型下载用 `HF_ENDPOINT=https://hf-mirror.com`（镜像可达）。
5. **pip 默认源慢**：装包用 `-i https://pypi.tuna.tsinghua.edu.cn/simple`。

**运行模板**：

## 在 `_james_work/` 跑通 3 个 laya × semantica 联动场景

**semantica** 是本地另一项目 `D:/_AllDocMap/02_Project/github/semantica`（Graph-Native 上下文与决策基础设施，v0.7.0）。与 laya 联动的核心是 `semantica.context` 的「决策智能生命周期」：Record → Link → Query → Govern。

**关键 API**（`from semantica.context import ContextGraph`，`graph = ContextGraph(advanced_analytics=False)`）：
- `record_decision(category, scenario, reasoning, outcome, confidence, entities=[], decision_maker=..., metadata={}) -> decision_id`
- `add_causal_relationship(src_id, tgt_id, "CAUSED"|"INFLUENCED"|"PRECEDENT_FOR") -> bool`
- `find_precedents_by_scenario(scenario, category, limit, similarity_threshold) -> [{decision, similarity}]`
- `trace_decision_causality(decision_id) -> List[{hops, interpretation, ...}]`
- `check_decision_rules(decision_data, rules) -> {compliant, violations, warnings}`（默认要求 confidence≥0.7、outcome∈[approved/rejected/flagged]、decision_maker 必填）
- `get_decision_insights() -> {total_decisions, categories, outcomes, confidence_stats}`

**产出**（3 个脚本，均已跑通）：
- `04_laya_semantica_record.py` — laya 工单分诊 → record_decision 决策记录 + 图溯源
- `05_laya_semantica_link_query.py` — laya 流失预警 → add_causal_relationship 因果链 + find_precedents_by_scenario 先例检索 + trace_decision_causality
- `06_laya_semantica_govern.py` — laya 退款审批 → check_decision_rules 策略合规门禁

**要点**：
- semantica 无需 pip install，`sys.path.insert(0, r"D:/_AllDocMap/02_Project/github/semantica")` 即可 import；核心依赖（networkx/numpy/scipy/sklearn/rdflib/pydantic/pyarrow）在 anaconda 已齐。
- 脚本内 `sys.path.insert` 同时加 laya 和 semantica 两个项目根，独立可运行（无需外部 PYTHONPATH）。
- **坑**：laya 用 2-option choice 做决策时，该 checkpoint 的 choice 置信度会因 temperature clamp 异常低（~0.0x，仍会触发 `RuntimeWarning: invalid temperatures`）；改用 `noul` 布尔判断（P(true) 的校准置信度）更可靠。
